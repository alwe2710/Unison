# assets/logo

`unison-logo.png` (1024×1024, opaque background) is the shared brand asset
for all clients — derive every platform's app/launcher icon from this one
file instead of maintaining separate art per platform. It's a black-flattened
copy of the source artwork (which has a genuinely transparent background);
platforms that support alpha (the web favicon, Android's inline drawable) can
still use the original transparent artwork directly instead where noted below.

Currently used by:

- `clients/android/app/src/main/res/mipmap-*/ic_launcher.png` +
  `ic_launcher_round.png` — plain resized copies (legacy square launcher
  icon, not an Android adaptive icon with separate foreground/background
  layers — the source has no transparent foreground to split out).
- `clients/android/app/src/main/res/drawable/unison_logo.png` — resized
  copy (192×192), used as the in-app top-bar logo (`MenuActivity`).
- `clients/3ds/icon.png` — source for the `.smdh` icon (24×24 + 48×48,
  platform-specific tiled RGB565 format, built via `bannertool`/`makerom`
  as part of the normal CMake build).
- `clients/3ds/cia/banner.png` + `banner_silent.wav` — CIA banner (exactly
  256×128, logo centered on the shared black background since bannertool
  needs that exact landscape aspect and the source is square); the audio
  track is unrelated to the logo and unchanged.
- `clients/switch/icon.jpg` — `.nacp` control data icon (256×256 JPEG),
  embedded into the `.nro` as part of the normal CMake build.
- `clients/nds/icon.bmp` — banner icon (32×32, 16-color indexed Windows 3.x
  BMP, matching devkitPro's own `calico/share/nds-icon.bmp` reference
  format exactly), wired in via `GAME_ICON` in `clients/nds/Makefile`. Built
  once from `unison-logo.png` via `Image.quantize(colors=16)` + resize to
  32×32 — not auto-regenerated by the script below, redo by hand if the
  source logo changes.
- `clients/web/favicon.png` (64×64) — **not** derived from `unison-logo.png`
  above; kept as its own file cropped straight from the original transparent
  artwork (browsers render PNG alpha fine, no black-flattening needed).
  Wired in via `<link rel="icon">` in `clients/web/index.html`.

Regenerate the Android mipmap icons + inline drawable after replacing
`unison-logo.png`:

```sh
python3 -c "
from PIL import Image
src = Image.open('assets/logo/unison-logo.png').convert('RGB')
sizes = {'mipmap-mdpi': 48, 'mipmap-hdpi': 72, 'mipmap-xhdpi': 96,
         'mipmap-xxhdpi': 144, 'mipmap-xxxhdpi': 192}
import os
for folder, size in sizes.items():
    d = f'clients/android/app/src/main/res/{folder}'
    os.makedirs(d, exist_ok=True)
    resized = src.resize((size, size), Image.LANCZOS)
    resized.save(f'{d}/ic_launcher.png')
    resized.save(f'{d}/ic_launcher_round.png')
src.resize((192, 192), Image.LANCZOS).save(
    'clients/android/app/src/main/res/drawable/unison_logo.png')
"
```

`clients/3ds/icon.png`, `clients/3ds/cia/banner.png` and
`clients/switch/icon.jpg` are simple resizes/crops of `unison-logo.png`
too, but aren't scripted (one-off, low churn) — regenerate by hand with the
same `Image.resize(..., Image.LANCZOS)` approach if the source logo changes.
